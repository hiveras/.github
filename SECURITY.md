# Security policy

This policy applies to every public Hiveras repository, unless a repository has its own `SECURITY.md`.

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue, discussion or pull request.

You can report in one of two ways:

- use **Report a vulnerability** on the Security tab of the repository (GitHub private vulnerability reporting); or
- email [hello@hiveras.com](mailto:hello@hiveras.com?subject=Security) with the subject line "Security".

Please include:

- which project and version or commit is affected;
- what the problem is and what someone could do with it;
- the steps to reproduce it.

Dutch or English is fine.

## What happens next

- We aim to confirm receipt within 3 working days.
- We investigate, keep you informed and tell you when a fix is ready.
- We credit you in the release notes if you wish.

Please give us reasonable time to fix the problem before you share it publicly.

## Supported versions

We support and patch the latest released version of each project.
